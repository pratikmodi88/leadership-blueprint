1. Strategic RAG Selection

The agent scans its proprietary 'Model Backlog' and uses RAG (Retrieval-Augmented Generation) to select the framework that best aligns with current leadership pillars and market trends.

2. Executive Summary Synthesis

Instead of generic text, the agent synthesizes the model into a professional, executive-level summary, ensuring the tone matches Pratik's leadership persona perfectly.

3. Real-time SVG Engineering

The agent generates a minimalist, high-quality SVG diagram from scratch to illustrate the model's core logic. No static assets are used; everything is built on the fly.

4. Automated Page Generation

A new, responsive HTML page is built using our Glassmorphism design language. The portfolio index is updated automatically to include the new model in the grid.

5. Git Deployment & Notification

The workflow closes by committing the changes and pushing to GitHub. Simultaneously, an email is triggered via the Resend API to notify all portfolio subscribers.
